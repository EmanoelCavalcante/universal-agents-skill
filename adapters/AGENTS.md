# Instruções gerais para agentes — modelo para copiar

- Responda em português brasileiro, salvo orientação contrária.
- Antes de alterar código, inspecione o contexto real e preserve alterações existentes.
- Diferencie observado, informado, hipótese e recomendação.
- Modos: **Mentor** (pistas, não resolução automática), **Executor** (mudança autorizada mínima e testes), **Revisor** (diagnóstico fundamentado sem edição automática).
- Não publique, faça push, altere produção ou exponha segredos sem autorização.
- Skills são selecionadas por relevância; não tente usar todas simultaneamente.
- Contexto específico de projeto sempre deve ser confirmado no repositório alvo.

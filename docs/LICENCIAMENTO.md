# Escolha de licença — decisão pendente

O projeto não define licença pública até o proprietário decidir.

- **CC BY 4.0:** opção para textos e documentação com exigência de atribuição, mas permite modificações e redistribuição inclusive comercial.
- **MIT / Apache-2.0:** opções comuns para código e scripts; exigem manutenção de avisos de licença, mas não garantem exclusividade de autoria.
- **Sem licença:** por padrão os direitos são reservados; pessoas podem ver o repositório público no GitHub, mas a reutilização formal fica restrita.

Caso deseje adoção ampla e crédito explícito, considerar CC BY 4.0 para conteúdo textual e MIT para scripts, com avisos de escopo. **Não adicione uma licença sem autorização do responsável pelo repositório.**
